# CRM Manager — мобильный клиент (Expo)

Минимальное приложение для полевых менеджеров: вход по учётке CRM, визиты на сегодня, старт/завершение визита с GPS, смена и топливо через API `/field/*`.

## Требования

- Node.js 20+
- [Expo CLI](https://docs.expo.dev/get-started/installation/) (или `npx expo`)
- На устройстве/эмуляторе приложение Expo Go или dev build

## Настройка API

Backend по умолчанию ожидается на порту **3001** (`http://localhost:3001`). Для симулятора/устройства **localhost недоступен** к хост-машине.

| Окружение | Пример URL |
|-----------|-------------|
| iOS Simulator (Mac + backend на том же Mac) | `http://localhost:3001` |
| Android Emulator | `http://10.0.2.2:3001` |
| Физическое устройство | `http://<IP вашего компьютера в LAN>:3001` |

Задайте переменную в корне приложения файлом `.env` (Expo автоматически подхватит переменные с префиксом `EXPO_PUBLIC_`):

```bash
EXPO_PUBLIC_API_URL=http://10.0.2.2:3001
```

Либо укажите `expo.extra.apiUrl` в `app.json`.

## Запуск

Из корня монорепо:

```bash
npm run dev:mobile
```

Или из этого каталога:

```bash
cd apps/mobile && npx expo start
```

Дальше: отсканируйте QR в терминале (Expo Go) или нажмите `i` / `a` для симулятора.

## Авторизация

Используются те же поля, что и для веб-CRM: **`login`** (email или username) и **пароль**. Ответ `/auth/login` (`token`) сохраняется в **Secure Store** и передаётся как `Authorization: Bearer …`.

Убедитесь, что в инстансе включён модуль **`ext.visits`**, иначе запросы к визитам и `/field/*` вернут отказ доступа.

## Структура экранов

- **Сегодня** — `GET /visits/day`, переход на карточку визита
- **Карта / Клиенты / Задачи** — заглушки для следующих итераций
- **Ещё** — смена (`/field/shifts/*`), топливо (`/field/fuel/day`), выход
