# CRM Manager — мобильный клиент (Expo)

Приложение для полевых менеджеров: визиты на сегодня, GPS при старте/завершении визита, **фоновый трек маршрута** во время смены, топливо через API `/field/*`.

## Требования

- Node.js 20+
- [Expo CLI](https://docs.expo.dev/get-started/installation/) (или `npx expo`)
- Для **фонового GPS** — dev build (EAS), не Expo Go

## Настройка API

Backend по умолчанию на порту **3001**. Для симулятора/устройства задайте `EXPO_PUBLIC_API_URL`:

```bash
EXPO_PUBLIC_API_URL=http://10.0.2.2:3001
```

| Окружение | Пример URL |
|-----------|-------------|
| iOS Simulator | `http://localhost:3001` |
| Android Emulator | `http://10.0.2.2:3001` |
| Физическое устройство | `http://<LAN-IP>:3001` |

## Запуск (разработка)

```bash
npm run dev:mobile
# или
cd apps/mobile && npx expo start
```

## Dev build (фоновый GPS)

Фоновая геолокация требует нативной сборки:

```bash
cd apps/mobile
npx eas-cli build --profile development --platform android
# или ios
```

Конфигурация: [`eas.json`](./eas.json), разрешения в [`app.json`](./app.json).

После установки dev build на устройство:

1. Войти в CRM
2. **Сегодня** → «Почати зміну» (или **Ще** → смена)
3. Разрешить геолокацию «Всегда» / фоновую
4. Баннер «Збір локацій активний» — точки уходят на `POST /field/shifts/:id/samples`

## Сценарий смены

| Шаг | Действие |
|-----|----------|
| Утро | Почати зміну, увімкнений «Збір треку» |
| День | Фоновые точки каждые ~3 мин / 50 м; GPS на старт/завершение визита |
| Вечер | Завершити зміну — трек останавливается, буфер отправляется |

Офлайн: точки буферизуются в AsyncStorage и отправляются при восстановлении сети.

## Модуль CRM

Включите **`ext.visits`**, иначе `/visits/*` и `/field/*` недоступны.

## Экраны

- **Сегодня** — визиты, CTA смены, баннер трекинга
- **Карта** — план / факт визитов / GPS-трек
- **Ще** — смена, статус flush, топливо
