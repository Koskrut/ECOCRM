# Дорожная карта реализации

## Сделано в репозитории (backend)

- Prisma-модели: `VisitGpsEvent`, доп. поля `Visit`, `UserFieldProfile`, `FieldShift`, `FieldLocationSample`, `FuelDayReport`.
- Верификация GPS в `VisitsService` при старт/комплит.
- REST: модуль Field (`/field/...`).
- Документация в `docs/mobile-manager-app/`.

## MVP (mobile + доработки backend)

| # | Задача |
|---|--------|
| 1 | Приложение: экран Сегодня, список `GET /visits/day`, старт смены |
| 2 | Интеграция карт/NAV deeplink к внешнему навигатору |
| 3 | Старт/завершение визита с геолокацией и отображением `gpsVerification` |
| 4 | Экран топлива и профиль авто |
