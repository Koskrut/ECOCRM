# Базовые функции менеджера в приложении

Функции согласованы с дорожной картой: **MVP** vs **последующие версии**.

## MVP (обязательно в первом релизе)

| Область | Функции |
|---------|---------|
| Визиты | План на день, старт/завершение, результат, заметки, GPS-верификация |
| Маршрут | Точки визитов, старт/конец смены |
| Клиенты | Поиск, карточка, звонок, связь с визитом |
| Задачи | Просмотр своих задач, закрытие простых задач (если API уже есть у CRM) |
| Топливо | Дневной отчёт по плановым км и профилю авто |
| Смена | Включение/выключение трекинга, границы рабочего дня |

## Версия 2

| Область | Функции |
|---------|---------|
| Заказы | Список по клиенту, статусы, повтор заказа (если поддерживается web API) |
| Документы | Просмотр КП/счетов из CRM |
| Коммуникации | Шаблоны сообщений, лог исходящих касаний |
| Офлайн | Очередь операций, синхронизация |

## Версия 3+

Антифрод трека, жёсткие политики завершения визита, утверждение компенсаций руководителем, аналитика эффективности маршрута.

Интеграция на backend для заказов/документов **не дублируется** здесь — мобильный клиент использует существующие защищённые эндпоинты NestJS там, где они уже есть.
